# Mascot Image Generation Prompts

Use these prompts in ChatGPT (DALL-E 3) or Gemini Image Generation. 
Match the existing Sheldon & Hariette art style: 3D Pixar/Disney-style render, 
soft warm lighting, clean neutral background, big expressive eyes, 
anthropomorphic but clearly animal, professional accessories, standing pose facing viewer.

## Style Matching Notes

When generating, reference these key traits from the existing mascots:
- **Sheldon**: Hard hat with "G&P Law", tool belt, holding a gavel and rolled document. Beige background.
- **Hariette**: Blue and yellow running shoes, energetic thumbs-up pose. Light blue background.
- Both have: smooth 3D rendering, subsurface scattering on skin/fur, soft shadows, 
  no harsh edges, warm color grading, slightly oversized heads/eyes for approachability.

If the first generation doesn't match, add: "in the exact same 3D rendered art style 
as [upload one of the existing mascot images as reference]"
